# اسکرپر جست‌وجوی دارو در ایران 🇮🇷

پروژه Python برای جست‌وجوی چندمنبعی اطلاعات عمومی دارو و محصولات دارویی/سلامتی در وب‌سایت‌های ایرانی، همراه با FastAPI و یک رابط PWA فارسی، راست‌چین و واکنش‌گرا.

> وضعیت فعلی: هسته اسکرپر، Adapterهای اختصاصی، API، تست‌های واحد/زنده و رابط PWA ساخته شده‌اند. پوشش همه منابع هنوز کامل نیست؛ بعضی سایت‌ها جست‌وجوی Dynamic یا endpoint متفاوت دارند.

## 1. عملکرد پروژه

کاربر نام دارو را وارد می‌کند. سیستم منابع را هم‌زمان بررسی کرده و در صورت پیدا شدن صفحه محصول، اطلاعاتی مانند نام محصول، برند، قیمت، واحد پول، موجودی آنلاین، شواهد موجودی، توضیحات، آدرس، تلفن، لینک، امتیاز تطابق، HTTP status و زمان بررسی را برمی‌گرداند.

نتایج مشابه نیز در بخش تجمیع محصولات مشابه گروه‌بندی می‌شوند.

### تفسیر درست نتیجه صفر

اگر result_count برابر صفر باشد، این الزاماً به معنی نبودن دارو نیست.

برای تفسیر نتیجه باید source_status را هم دید. مثلاً:

- status=ok و search_links=0 یعنی صفحه جست‌وجو دریافت شده، ولی Adapter فعلی لینک قابل استفاده‌ای استخراج نکرده است.
- status=error یعنی آن منبع در همان جست‌وجو قابل بررسی نبوده است.
- parsed_products=0 یعنی از لینک‌های استخراج‌شده محصول قابل Parse پیدا نشده است.

بنابراین نتیجه صفر باید به صورت «در منابع فعلی نتیجه قابل استخراج پیدا نشد» تفسیر شود، نه «دارو قطعاً وجود ندارد».

## 4. نمونه تست واقعی

در تست زنده پروژه عبارت «مگنیفورت» بررسی شده است.

داروکالا:
- محصول: کپسول مگنیفورت آرین سلامت سینا
- HTTP: 200
- قیمت استخراج‌شده: 3,799,000
- واحد گزارش‌شده: IRR

داروهوم:

این اعداد مربوط به زمان همان تست هستند.

## 5. اجرای پروژه

### پیش‌نیاز

برای Windows در وضعیت فعلی پروژه Python 3.12 توصیه می‌شود. Python 3.14 ممکن است برای بعضی وابستگی‌ها به Build از سورس و Rust/Cargo نیاز پیدا کند.

بررسی نسخه‌ها:

    py -0p
    py -3.12 --version

نصب وابستگی‌ها:

    py -3.12 -m pip install -r requirements.txt

اجرای CLI:

    py -3.12 cli.py

اجرای وب:

    py -3.12 main.py

بعد مرورگر را باز کنید:

    http://127.0.0.1:8000/

## 7. API

جست‌وجو:

    GET /api/search?q=نام%20دارو

مثال:

    http://127.0.0.1:8000/api/search?q=مگنیفورت

Health check:

    GET /api/health

خروجی شامل query، checked_at، result_count، sources_checked، source_status، results، grouped و note است.

## 11. جست‌وجوی گارداسیل9

نرمال‌سازی جدید عبارت‌های متصل به عدد را بهتر یکسان می‌کند؛ بنابراین گارداسیل9 و گارداسیل ۹ از نظر تطبیق نزدیک‌تر هستند.

با این حال اگر همه منابع search_links=0 بدهند، هنوز نمی‌توان گفت محصول وجود ندارد یا ندارد؛ این فقط نشان‌دهنده محدودیت Adapter فعلی در استخراج صفحه جست‌وجو است.

## 12. محدودیت‌های مهم

- موجودی آنلاین مساوی موجودی فیزیکی قطعی نیست.
- قیمت مربوط به زمان بررسی است.
- صفحه محصول مساوی موجود بودن نیست.
- وجود صفحه فروش اینترنتی به معنی مجاز بودن فروش داروی نسخه‌ای بدون نسخه نیست.
- خطای شبکه مساوی نبودن دارو نیست.
- search_links=0 مساوی نبودن محصول نیست.
- نتیجه هر منبع باید همراه با زمان و وضعیت همان منبع تفسیر شود.

## 13. استفاده مسئولانه
